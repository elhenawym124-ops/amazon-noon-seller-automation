## قواعد تشغيل سريعة

- **حساب واحد = بروفايل واحد.** لا تخلط Level-Up وHomeVista في نفس الجلسة.
- **قبل أي دفعة:** افتح الحساب، اتأكد من تسجيل الدخول، واعمل batch صغير.
- **بعد أي دفعة:** نزّل Processing Summary واحفظه في `amz-upload/summaries/`.
- **أي خطأ جديد:** يتسجل هنا كدرس مستفاد بدل ما يتكرر.
